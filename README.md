# SmartCart Customer Segmentation System

## Overview

This project uses Unsupervised Machine Learning to segment customers based on their purchasing behaviour and demographic information.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm

- K-Means Clustering

## Workflow

- Data Cleaning
- Feature Selection
- Feature Scaling
- K-Means Clustering
- Elbow Method
- Silhouette Score
- Customer Segmentation

## Dataset

The dataset contains customer demographics, purchase history, website activity, and engagement information.
